# Contributing to Needle MCP

We welcome contributions to Needle MCP. To ensure a smooth experience, please follow these guidelines:

1. **Fork the repo.**
2. **Feature branches.** Use branches like `feat/something` or `fix/issue`.
3. **Linting.** Run `uvx ruff check .` and `uvx ruff format .` before committing.
4. **Pull Requests.** Open a PR with a description of your changes.
